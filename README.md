# DarziVid 👗✂️

DarziVid is an Android application for online tailoring services.  
Customers can search tailors, book stitching services, and manage measurements digitally.

## Features 🚀

### Customer Module
- Search tailor by location
- Book stitching appointments
- Store clothing measurements
- Online payment support

### Tailor Module
- Manage customer orders
- View measurements
- Handle stitching services
- Payment dashboard

## Technologies Used 🛠️
- Kotlin
- XML
- Android Studio
- Firebase
- Firebase Database

## Project Structure 📁
- Customer Module
- Tailor Module
- Authentication
- Booking System
- Measurement Management
